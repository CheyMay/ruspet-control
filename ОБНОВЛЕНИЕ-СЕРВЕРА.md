# Обновление РУСПЭТ из GitHub

Облачный Codex вносит изменения в приватный репозиторий `CheyMay/ruspet-control`. Рабочая ветка `pilot/november-13`. Перед выкладкой убедитесь, что нужный коммит уже в этой ветке.

Войдите по SSH на рабочий VPS. Из консоли под root выполните.

```bash
GIT_SSH_COMMAND='ssh -i /root/.ssh/ruspet_github -o IdentitiesOnly=yes -o BatchMode=yes' git -C /root/ruspet-code fetch origin pilot/november-13
git -C /root/ruspet-code show FETCH_HEAD:scripts/update-server.sh > /root/update-ruspet.sh
bash /root/update-ruspet.sh --apply
```

Чтобы поставить конкретный коммит, укажите полный SHA.

```bash
RUSPET_UPDATE_REVISION=ПОЛНЫЙ_SHA bash /root/update-ruspet.sh --apply
```

`--prepare` собирает выпуск и проверяет его без переключения служб. `--apply` сохраняет дампы и предыдущий код, применяет миграции и проверяет сайт. При сбое запуска скрипт восстанавливает предыдущий код, зависимости и сборку. Применённые добавочные миграции сохраняются. Для миграции, меняющей или удаляющей рабочие данные, сначала нужен отдельный план совместимости и отката.

Проверка после выкладки.

```bash
curl -fsS https://cheymay.ru/api/health
systemctl is-active ruspet.service ruspet-bot-proxy.service
cat /opt/ruspet/.voice-tasks-release
```

База, `.env`, файлы ключей и конфигурация systemd остаются на сервере. Telegram продолжает работать в одном процессе. Для разбора ошибки сохраните SHA, путь резервной копии из вывода и первую ошибку. Секреты и дампы в Git не добавляйте.
